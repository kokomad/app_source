# لانشر خضر (Khader Launcher)

لانشر أندرويد حقيقي (Kotlin) بتصميم زجاجي احترافي.

- ساعة وتاريخ وبطارية على الشاشة الرئيسية
- بطاقة "الأكثر استخداماً" + شريط سفلي (٤ تطبيقات قابلة للتثبيت)
- درج تطبيقات بسحب للأعلى مع بحث فوري
- ضغط مطول على أي تطبيق: تثبيت / معلومات / إلغاء تثبيت
- ضغط مطول على الشاشة: تغيير الخلفية، لون التمييز، الإعدادات
- سحب للأسفل لفتح الإشعارات
